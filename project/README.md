# Graph algorithms

The project is a Cargo workspace. Run the following commands from this directory.

## Build and test

```sh
cargo build --workspace
cargo test --workspace
```

## Run

```sh
cargo run -p demo
cargo run -p cli
cargo run -p performance-experiments
cargo run -p memory-experiments
cargo run -p experiments-rq1
cargo run -p experiments-rq2
```

The binaries are currently placeholders; the experiment commands do not yet run measurements.
